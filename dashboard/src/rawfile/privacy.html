Dashboard 应用看板隐私政策

更新及生效日期：2026 年 9 月 21 日

Dashboard 应用看板用于查询应用市场公开数据与统计图表。数据仅供参考，不代表任何平台的官方运营数据。

1. 我们处理哪些信息

  • 浏览与查询：应用会把您选择的筛选条件、包名、App ID 或搜索文字发送到项目后端，以返回相应公开数据。网络服务通常会接收到 IP 地址等完成通信所必需的信息。
  • 投稿与更新：只有在您主动提交时，应用才会发送包名或 App ID。您在设置中填写的用户名会作为投稿备注一并发送；用户名可以留空。
  • 请求标识：请求会携带只包含应用标识、版本、平台类别与操作系统名称的 User-Agent，不包含精确设备型号或设备唯一标识符。
  • 无设备遥测：Apple 原生版不会另行上报设备型号、序列号、广告标识符或自行生成的跨安装标识。
  • 本地数据：搜索历史、用户名、触感偏好、重要提示确认状态及 API 缓存保存在本机，用于提供相应功能与离线回退。

2. 网页与第三方服务

原生界面是主要入口。只有当您主动打开备用网页、API 文档、应用市场详情、友情链接、社区频道或赞助页面时，内容才会由相应网站提供。内嵌网页可能按其自身政策使用 Cookie 或网页存储；外部站点的内容、数据处理和条款由其运营方负责。

3. 数据存储与清除

API 缓存最多可在本机保留 30 天，用于网络失败时显示最近数据。您可以在“我的 → 清除缓存”中删除 API 缓存、网页存储与 Cookie；该操作不会删除用户名与偏好设置。搜索历史可在搜索页单独清除。您也可以通过系统删除应用及其本地数据。

4. 系统权限

Apple 原生版不请求通讯录、照片、定位、麦克风、摄像头、蓝牙或附近设备权限。打开系统浏览器、复制联系方式和系统分享均由您主动触发，并由 Apple 平台组件处理。

5. 安全与数据范围

应用仅通过 HTTPS 访问远程服务，限制单次 API 响应大小并设置超时。数据收录范围为正式公开发布的应用与元服务，不包含侧载、公开测试或邀请测试内容。公开数据仍可能因同步间隔、数据源变化和网络状态而延迟。

6. 儿童隐私

本应用不面向儿童收集个人信息，也不提供账户注册或个性化广告。未成年人应在监护人指导下使用外部链接与社区服务。

7. 政策更新

功能或数据处理方式发生实质变化时，我们会更新本政策，并在应用内通过更新日志或提示说明。继续使用前，请留意政策顶部的更新日期。

8. 联系我们

如对隐私、数据更正或删除有疑问，请联系：rayawa.work@outlook.com。应用内“我的 → 联系我们”也提供项目相关联系方式。
